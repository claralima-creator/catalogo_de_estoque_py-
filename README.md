# 📦 Catálogo de Estoque e Etiquetas de Produtos (CLI)

Projeto desenvolvido em Python com o objetivo de criar um sistema simples de gerenciamento de estoque por meio do terminal (CLI).

A aplicação permite cadastrar produtos, aplicar descontos, comparar etiquetas e gerenciar as informações dos produtos cadastrados.

## 🚀 Funcionalidades

- **Cadastro de produtos:** registra SKU, nome, preço, quantidade e etiquetas.
- **Validação de dados:** verifica se o preço e a quantidade são valores numéricos válidos e positivos.
- **Aplicação de descontos:** calcula o valor do desconto, o preço final e a economia.
- **Comparação de etiquetas:** identifica etiquetas em comum, exclusivas e presentes apenas no primeiro produto.
- **Gerenciamento de etiquetas:** permite adicionar ou remover etiquetas de um produto.
- **Relatório de estoque:** calcula o valor total dos produtos em estoque e reúne todas as etiquetas cadastradas.
